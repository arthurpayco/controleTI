☁ Sincronizar com o GitHub

Salve e carregue os dados direto de um repositório do GitHub — sem exportar/importar arquivo. Use um repositório privado e um token com permissão apenas de Contents (leitura e escrita).

Como configurar (passo a passo)
  1. Crie um repositório privado no GitHub (ex.: organograma-dados).
  2. Vá em Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Em Repository access, escolha Only select repositories e selecione o repositório criado.
  4. Em Permissions → Repository → Contents, marque Read and write.
  5. Gere o token, copie e cole no campo Token acima.
  6. Preencha usuário/repositório, clique em Salvar na nuvem. Depois marque salvar automaticamente.

O token fica guardado apenas neste navegador. Mantenha o repositório privado.
